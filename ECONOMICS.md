
# Unit Economics - AI Spend Audit

## Value Per Converted Lead

**Assumptions:**
- Average Credex customer spends $5,000/month on AI tools
- Credex discount: 20-30% → $1,000-1,500 savings per month
- Credex takes 50% of savings as margin → $500-750/month per customer
- Customer lifetime value (LTV): 12 months average → $6,000-9,000 per customer

**Conversion funnel:**
1,000 Audits → 100 High-savings (>$500) → 10 Consultations → 2 Purchases

**Value per audit:**
- 2 purchases × $7,500 average LTV = $15,000 revenue
- $15,000 ÷ 1,000 audits = **$15 value per audit**

## Customer Acquisition Cost (CAC)

| Channel | CAC Estimate | Volume Potential |
| :--- | :--- | :--- |
| Organic (SEO, Hacker News) | $0 | 500 users/month |
| Social (Twitter, Reddit) | $5-10 | 200 users/month |
| Content marketing | $2-5 | 300 users/month |
| Paid ads (LinkedIn, Reddit) | $15-20 | 500 users/month |

**Weighted average CAC:** ~$8 per user

## Conversion Rates Needed for Profitability

| Funnel Step | Conversion Rate | Volume Needed |
| :--- | :--- | :--- |
| Visit → Audit | 60% | - |
| Audit → High-savings (>$500) | 10% | - |
| High-savings → Consultation | 10% | 100 consultations |
| Consultation → Purchase | 20% | 20 purchases |
| **Overall conversion** | **0.12%** | **16,667 audits** |

**Break-even point:**
- CAC per audit: $0 (organic) to $8 (paid)
- Value per audit: $15
- Profit per audit (organic): $15
- Audits needed for $100K profit: ~6,667

## Path to $1M ARR in 18 Months

| Metric | Year 1 | Year 2 (ARR target) |
| :--- | :--- | :--- |
| Monthly audits | 5,000 | 20,000 |
| High-savings leads | 500 | 2,000 |
| Consultations | 50 | 200 |
| New customers | 10 | 40 |
| Average LTV per customer | $7,500 | $7,500 |
| New ARR from tool | $75,000 | $300,000 |
| Credex total ARR (other channels) | $700,000 | $700,000 |
| **Total ARR** | **$775,000** | **$1,000,000+** |

**Key assumptions validated:**
1. The AI tool market continues growing 30%+ YoY
2. Credex's discount model remains competitive
3. The tool converts at 0.12% (audit → customer)
4. 20,000 monthly audits achievable with good SEO

## What Would Have to Be True

For this tool to drive $1M ARR, these must be true:

1. **Market growth** - AI tool spending continues increasing
2. **Viral coefficient >1** - Each user shares with at least 1.5 others
3. **SEO dominance** - Rank #1 for "AI spend audit" and related terms
4. **Product-market fit** - 40%+ of users return monthly
5. **Credex integration** - Sales team effectively follows up on leads

## Sensitivity Analysis

| Variable | Bear Case | Base Case | Bull Case |
| :--- | :--- | :--- | :--- |
| Audit → Purchase | 0.05% | 0.12% | 0.25% |
| Monthly audits | 5,000 | 20,000 | 50,000 |
| Annual customers | 30 | 288 | 1,500 |

**Takeaway:** Even in bear case, the tool pays for itself. In bull case, it becomes Credex's primary customer acquisition channel.
